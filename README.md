# Świat Psów
Projekt wykonany w ramach zajęć z Aplikacji internetowych

## Opis projektu
Strona internetowa poświęcona psom. Zawiera informacje i materiały związane z tematyką projektu. Wszystkie zdjęcia pochodzą z osobistej galerii zdjęć.

## Technologie
- HTML5
- CSS3
- JavaScript

## Funkcjonalności
- Quiz o psach
- Zmiana motywu jasny/ciemny
- Przycisk powrotu na górę strony
